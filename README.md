OFFICE BREAKDOWN
A 2D stickman game about the chaos of office life.

OFFICE BREAKDOWN is a browser-based game project featuring minimalist stickman characters, an office-themed arena, and local two-player combat.
Game Modes
LAYOFF LEGENDS
A local 1v1 fighting mode featuring punches, kicks, special moves, animated ties, and cinematic knockout sequences.
Planned Modes
- DEADLINE DASH — competitive office parkour racing.
- PACKAGE PANIC — a cooperative physics-based delivery challenge.
Note: DEADLINE DASH and PACKAGE PANIC are planned modes and should not be described as playable until implemented.

How to Play Locally
1. Download or clone this repository.
2. Open the game's HTML file in a modern browser.
3. Follow the controls displayed in the game.
If the project is split into multiple HTML, CSS, or JavaScript files, keep the files together in their original folder structure.
Play Online
The game can be hosted for free using GitHub Pages.
1. Put the playable HTML file in the repository root and rename it to index.html.
2. Commit and push the file to the main branch.
3. Open Settings → Pages in this repository.
4. Under Build and deployment, select Deploy from a branch.
5. Select branch main and folder /(root), then click Save.
6. Wait for deployment to finish. GitHub will show the published site link in the Pages settings.
The expected project URL is:

https://srikarexe.github.io/Office-Breakdown/

This link will work only after GitHub Pages has been enabled and the game file has been committed to the repository as index.html.
